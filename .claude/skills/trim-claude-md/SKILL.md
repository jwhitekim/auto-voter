`.claude/CLAUDE.md`를 읽고:

1. 현재 줄 수를 보고한다
2. "절대 하지 말 것"과 "완료 조건"처럼 매번 지켜야 하는 규칙만 남긴다
3. 배경 설명("왜")에 해당하는 부분은 `docs/` 아래 적절한 파일로 옮기고, `CLAUDE.md`에는 그 파일 경로만 링크로 남긴다
4. 옮기기 전/후 줄 수를 비교해서 보고한다
5. 실제로 파일을 옮기기 전에 사람에게 계획을 먼저 보여주고 승인받는다

| 남기는 것 | 옮기는 것 |
|---|---|
| 절대 하지 말 것 (자주 걸리는 것) | 배경 설명, 왜 그런지 |
| 완료 조건 | 특정 기능에만 해당하는 규칙 |
| 파일 위치 지도 (docs/ 참조 링크) | 예시, 상세 절차 |
