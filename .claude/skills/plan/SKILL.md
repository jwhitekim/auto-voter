아래 요청에 대해 지금 바로 코드를 쓰지 않는다.

1. 요청을 다시 말로 정리해서 확인받는다
2. 불확실한 부분이 있으면 가정하지 말고 질문한다
3. 작은 단계로 나눈 계획을 제시한다 (각 단계 → 검증 방법 포함)
4. `EnterPlanMode` 도구를 사용해 실제로 플랜 모드로 들어간다 — 사람이 승인할 때까지 코드를 쓰지 않는다
